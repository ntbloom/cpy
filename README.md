# cpy

Example project for integrating Python/C++ code using `uv` and a modern toolkit.

Tools used:

* `scikit-build`
* `pybind11`
* `uv`
* `cmake`

On display:

* Supports `compile-commands.json` for editor support, with full paths to all pybind headers
* Working test suite
* Makefile for standard uv command invocations
